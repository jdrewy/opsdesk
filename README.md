
# OpsDesk

An IT Support & Incident Management Platform.

## Overview

OpsDesk is a portfolio project designed to simulate
how an organization's IT department manages incidents,
support requests, and ticket resolution workflows.

## Planned Features

- Incident ticket creation and management
- Ticket priorities and status tracking
- IT technician assignment
- User authentication and role-based access
- Incident analytics and reporting
- SLA monitoring

## Technology Stack

- Frontend: React, TypeScript, Vite
- Backend (planned): Node.js, Express
- Database (planned): PostgreSQL
- Version Control: Git and GitHub

## Running Locally

Install Node.js, then run:

```powershell
cd client
npm.cmd install
npm.cmd run dev
```

Open http://localhost:5173/
